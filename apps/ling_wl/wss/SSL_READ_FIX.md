# SSL读取逻辑修复文档

## 问题
WSS模式下，代码无条件尝试读取SSL数据（即使select未检测到可读事件），导致在无数据时触发 `[ws_custom]SSL read error` 错误。

## 修复
统一SSL和非SSL的读取逻辑：仅在 `select` 检测到可读事件时读取数据。

## 修改内容
- **第1090-1092行**：删除过时注释
- **第1091行**：统一超时处理 `if (ret == 0) continue;`
- **第1093行**：删除 `|| client->use_ssl` 条件，统一读取条件
- **第1108行**：删除重复的 `FD_ISSET` 判断

## 效果
- SSL和非SSL使用相同读取逻辑
- 避免无数据时强制读取导致的错误
- 减少错误日志输出
